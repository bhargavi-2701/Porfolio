BHARGAVI PORTFOLIO

Files included:
- index.html: main portfolio webpage
- css/style.css: layout, colours, responsive styling
- js/script.js: mobile navigation and current year
- images/girl-working.svg: original illustration used on the home page

HOW TO OPEN
1. Extract/unzip this folder.
2. Open index.html in Chrome, Edge, Firefox, or another browser.
3. Keep the css, js, and images folders next to index.html so the page works correctly.

To edit your details, open index.html in a text editor. The current contact details are the ones provided for this portfolio. The girl image is an illustration, not a personal photo.
